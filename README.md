# Steve Walker Memorial

A simple, responsive memorial website template built with Next.js, React, TypeScript, and Tailwind CSS.

## Getting started

Install dependencies and start the local development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Personalizing the template

The main content is in `app/page.tsx`. Update the placeholder dates, memories, biography, family attribution, and tribute email address there.

The color palette and layout styles are in `app/globals.css`. The social sharing image is `public/og.png`.

## Production

```bash
npm run build
npm start
```

The app can be deployed anywhere that supports Next.js.
